# LumiRose v1.1 重构实施计划

> **供执行 Agent 使用：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐个执行本计划。使用复选框（`- [ ]`）跟踪进度。

**目标：** 用当前 v1.1 规格替换旧的 v1.1 实现：SSE-only 客户端、单一 Agent 循环、带 `deltas()` 的 `LumiRoseResult`、上下文压缩、entity/DTO/DO 分层，以及原子化的 `ConversationRepository`。

**架构：** 从干净的源码树开始。`LumiRoseClient` 负责 HTTP/SSE 解析；`LumiRoseAgent` 负责加载、压缩、轮次循环、工具、重试、取消和一次提交；`ConversationRepository` 负责存储和会话行创建。Entity 是业务模型，DTO 只用于协议，DO/Converter 只用于持久化。

**技术栈：** Java 21、Maven 3.9、OkHttp 4.12.0、Jackson 2.18.3、SLF4J 2.0.17、JUnit 5.12.2、Logback 1.5.38（仅测试）。

**规格：** `docs/v1.1/requirements/v1.1.md`；详细测试用例：`docs/v1.1/testing/v1.1.md`。

**代码范围：** 每个任务的实现步骤内联该任务创建或修改的**完整生产代码**；测试代码不在本计划内，测试步骤给出用例、断言与命令。

## 全局约束

- Java 21；`maven.compiler.release=21`；构建命令为 `mvn -o test`，必须离线通过。
- 不新增依赖。运行时：OkHttp、Jackson、SLF4J。测试：JUnit Jupiter、Logback。
- 禁止使用 `record`：实体、DTO、DO、测试夹具一律使用 `final class`，显式写构造器和访问器；不要依赖 record 自动生成的 `equals`/`hashCode`/`toString`。
- 公开 API 类型用 `public final class` 或 `public interface`；内部实现（如 `SseAccumulator`、`AgentResult`、`Workspace`）用包内可见或 `private`。
- 代码块只列签名时，公开类的构造器、访问器和 builder 方法在实现时必须是 `public`，接口方法隐式 `public`。
- 包根路径：`io.github.xxxyjade.lumirose`；源文件 UTF-8，4 空格缩进。
- 持久化 DO 的包是 `model.data`，不能写成 `model.do`：`do` 是 Java 关键字。
- 公开入口：`LumiRoseAgent.run(long, String)`、`streamRun(long, String)`、`LumiRoseResult`、`LumiRoseClient`、`model.dto.chat.*`、`model.entity.*`、`common.exception.*`、`common.enums.*`、`ConversationRepository`、`InMemoryConversationRepository`、`Tool`、`ToolContext`、`ToolParameters`、`EmptyParameters`、`tool.impl.*`。
- `conversationId` 是非空 `long`；框架从不生成 id。
- 不存在 `RunResult`、`ToolCallRecord`、`MetricsRecorder`、`runResult`、公开的 `StreamListener`/`StreamControl`、`MessageRepository`、`ConversationLocks`、`RetryPolicy`、`ContextTrimmer`、`ResultChannel` 或 `compressionSummaryMaxTokens`。
- `LumiRoseResult` 不继承 `AutoCloseable`，且没有 `close()`；取消使用 `cancel()`。
- 默认值：`maxTurns=10`、`maxRetries=0`、重试基数 500ms、最大 8000ms、threshold 0.65、connect 10s、write 30s、read 120s，不设整体 SSE 超时。
- 摘要 `max_tokens` 为 `min(2048, max(1, floor(window × (1 - threshold) × 0.7)))`。
- `content()` 是所有 assistant 正文的拼接，包含工具轮前言；`deltas()` 拼接后得到相同值。
- 异常/日志绝不包含 API Key、消息内容、工具参数/结果、请求/响应体或供应商 `error.message`。
- 测试使用 `FakeServer`；不依赖真实 Key、网络、实际时钟 sleep 或执行顺序。

## 评审重点

以下是规格隐含、但只实现正常路径时最容易做错的输入/条件：

1. 带正文前言的工具轮：下一次请求必须包含上一轮的 `assistant(tool_calls)` 和工具结果，且前言必须同时出现在 `deltas()` 和 `content()` 中。
2. 压缩后 chat 响应缺少 usage：必须报 `3005` 且不写入，不能保存压缩前的 `contextTokens`。
3. 空仓储的首次写入：`append`/`compact` 必须创建 `conversations` 行；只有 `load` 时不得创建。
4. HTTP 400 响应体含 prompt 文本：异常中只能出现状态码/code/type，不能出现供应商 `error.message`。
5. 流式取消：不再产生 delta、报 `3004`、不提交，且 `deltas()` 仍只能迭代一次。

上述各项分别对应验收项 A02、A13、A15、A18、A08；具体归属任务见下文。

```java
        return messages;
    }
```

```java
        }
        List<ToolCall> toolCalls = new ArrayList<>();
        if (toolCallDOs != null) {

            case ASSISTANT -> Message.assistant(messageDO.content(),
                    messageDO.reasoningContent(), toolCalls);
            case TOOL -> Message.tool(messageDO.toolCallId(), messageDO.content());
        };
    }

    public static MessageDO toDo(long id, long conversationId, Message message,
                                 boolean active, Instant now) {
        return new MessageDO(id, conversationId, message.role(), message.content(),
```

```java
package io.github.xxxyjade.lumirose.repository;

import io.github.xxxyjade.lumirose.common.exception.AgentException;
import io.github.xxxyjade.lumirose.common.exception.LumiRoseErrorCode;
import io.github.xxxyjade.lumirose.model.convert.MessageConverter;
import io.github.xxxyjade.lumirose.model.convert.ToolCallConverter;
import io.github.xxxyjade.lumirose.model.data.MessageDO;
import io.github.xxxyjade.lumirose.model.data.ToolCallDO;
import io.github.xxxyjade.lumirose.model.entity.Conversation;
import io.github.xxxyjade.lumirose.model.entity.Message;
import io.github.xxxyjade.lumirose.model.entity.ToolCall;

import java.time.Instant;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.atomic.AtomicLong;

public final class InMemoryConversationRepository implements ConversationRepository {
    private final ConcurrentHashMap<Long, StoredConversation> conversations = new ConcurrentHashMap<>();
    private final AtomicLong messageIds = new AtomicLong();
    private final AtomicLong toolCallIds = new AtomicLong();

    @Override
    public Conversation load(long conversationId) {
        StoredConversation stored = conversations.get(conversationId);
        if (stored == null) {
            return Conversation.empty(conversationId);
        }
        synchronized (stored) {
            List<Message> messages = stored.messages.stream()
                    .filter(item -> item.message.active())
                    .sorted(Comparator.comparingLong(item -> item.message.id()))
                    .map(item -> MessageConverter.toEntity(item.message, item.toolCalls))
                    .toList();
            return Conversation.of(conversationId, messages, stored.contextTokens);
        }
    }

    @Override
    public void append(long conversationId, List<Message> pending, int contextTokens) {
        if (pending == null) {
            throw new AgentException(LumiRoseErrorCode.PARAM_INVALID, "pending 不能为空");
        }
        if (pending.isEmpty()) {
            return;
        }
        if (contextTokens < 0) {
            throw new AgentException(LumiRoseErrorCode.PARAM_INVALID, "contextTokens 不能为负");
        }
        Instant now = Instant.now();
        conversations.compute(conversationId, (id, existing) -> {
            StoredConversation stored = existing == null ? new StoredConversation(id, now) : existing;
            synchronized (stored) {
                for (Message message : pending) {
                    addMessage(stored, message, true, now);
                }
                stored.contextTokens = contextTokens;
                stored.updatedAt = now;
            }
            return stored;
        });
    }

    @Override
    public void compact(long conversationId, Message summary, List<Message> pending, int contextTokens) {
        if (summary == null) {
            throw new AgentException(LumiRoseErrorCode.PARAM_INVALID, "summary 不能为空");
        }
        if (pending == null) {
            throw new AgentException(LumiRoseErrorCode.PARAM_INVALID, "pending 不能为空");
        }
        if (contextTokens < 0) {
            throw new AgentException(LumiRoseErrorCode.PARAM_INVALID, "contextTokens 不能为负");
        }
        Instant now = Instant.now();
        conversations.compute(conversationId, (id, existing) -> {
            StoredConversation stored = existing == null ? new StoredConversation(id, now) : existing;
            synchronized (stored) {
                for (StoredMessage message : stored.messages) {
                    message.deactivate();
                }
                addMessage(stored, summary, true, now);
                for (Message message : pending) {
                    addMessage(stored, message, true, now);
                }
                stored.contextTokens = contextTokens;
                stored.updatedAt = now;
            }
            return stored;
        });
    }

    private void addMessage(StoredConversation stored, Message message, boolean active, Instant now) {
        long messageId = messageIds.incrementAndGet();
        MessageDO messageDO = MessageConverter.toDo(messageId, stored.id, message, active, now);
        List<ToolCallDO> toolCalls = new ArrayList<>();
        for (int index = 0; index < message.toolCalls().size(); index++) {
            ToolCall toolCall = message.toolCalls().get(index);
            ToolCallDO converted = ToolCallConverter.toDo(messageId, index, toolCall, now);
            toolCalls.add(new ToolCallDO(toolCallIds.incrementAndGet(), messageId, index,
                    converted.callId(), converted.callType(), converted.functionName(),
                    converted.arguments(), now));
        }
        stored.messages.add(new StoredMessage(messageDO, List.copyOf(toolCalls)));
    }

    private static final class StoredConversation {
        private final long id;
        private final Instant createdAt;
        private final List<StoredMessage> messages = new ArrayList<>();
        private int contextTokens;
        private Instant updatedAt;

        private StoredConversation(long id, Instant now) {
            this.id = id;
            this.createdAt = now;
            this.updatedAt = now;
        }
    }

    private static final class StoredMessage {
        private MessageDO message;
        private final List<ToolCallDO> toolCalls;

        private StoredMessage(MessageDO message, List<ToolCallDO> toolCalls) {
            this.message = message;
            this.toolCalls = toolCalls;
        }

        private void deactivate() {
            MessageDO old = message;
            message = new MessageDO(old.id(), old.conversationId(), old.role(), old.content(),
                    old.reasoningContent(), old.toolCallId(), false, old.createdAt(), old.updatedAt());
        }
    }
}
```

```java
package io.github.xxxyjade.lumirose.tool;

import com.fasterxml.jackson.annotation.JsonProperty;
import com.fasterxml.jackson.annotation.JsonPropertyDescription;
import com.fasterxml.jackson.databind.JsonNode;
import com.fasterxml.jackson.databind.node.ArrayNode;
import com.fasterxml.jackson.databind.node.JsonNodeFactory;
import com.fasterxml.jackson.databind.node.ObjectNode;
import io.github.xxxyjade.lumirose.common.exception.ConfigurationException;
import io.github.xxxyjade.lumirose.common.exception.LumiRoseErrorCode;

import java.lang.reflect.Field;
import java.lang.reflect.Modifier;
import java.lang.reflect.ParameterizedType;
import java.lang.reflect.Type;
import java.math.BigDecimal;
import java.time.temporal.Temporal;
import java.util.Date;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.Optional;
import java.util.Set;

public final class ToolSchemaFactory {
    private static final JsonNodeFactory NODES = JsonNodeFactory.instance;

    private ToolSchemaFactory() {
    }

    public static JsonNode generate(Class<?> parametersType) {
        if (parametersType == null) {
            throw invalid("参数类型不能为空");
        }
        return objectSchema(parametersType, new HashSet<>());
    }

    private static ObjectNode objectSchema(Class<?> type, Set<Class<?>> stack) {
        if (!stack.add(type)) {
            throw invalid("参数类型不能递归引用");
        }
        ObjectNode schema = NODES.objectNode();
        schema.put("type", "object");
        ObjectNode properties = schema.putObject("properties");
        ArrayNode required = NODES.arrayNode();
        for (Field field : type.getDeclaredFields()) {
            if (Modifier.isStatic(field.getModifiers()) || field.isSynthetic()) {
                continue;
            }
            JsonProperty jsonProperty = field.getAnnotation(JsonProperty.class);
            if (jsonProperty == null) {
                continue;
            }
            String name = jsonProperty.value().isEmpty() ? field.getName() : jsonProperty.value();
            ObjectNode fieldSchema = fieldSchema(field.getType(), field.getGenericType(), stack);
            JsonPropertyDescription description = field.getAnnotation(JsonPropertyDescription.class);
            if (description != null && !description.value().isEmpty()) {
                fieldSchema.put("description", description.value());
            }
            properties.set(name, fieldSchema);
            if (jsonProperty.required()) {
                required.add(name);
            }
        }
        stack.remove(type);
        if (!required.isEmpty()) {
            schema.set("required", required);
        }
        return schema;
    }

    private static ObjectNode fieldSchema(Class<?> raw, Type generic, Set<Class<?>> stack) {
        if (raw == String.class || raw == char.class || raw == Character.class) {
            return stringSchema();
        }
        if (raw == int.class || raw == Integer.class || raw == long.class || raw == Long.class
                || raw == short.class || raw == Short.class || raw == byte.class || raw == Byte.class) {
            ObjectNode node = NODES.objectNode();
            node.put("type", "integer");
            return node;
        }
        if (raw == float.class || raw == Float.class || raw == double.class || raw == Double.class
                || raw == BigDecimal.class) {
            ObjectNode node = NODES.objectNode();
            node.put("type", "number");
            return node;
        }
        if (raw == boolean.class || raw == Boolean.class) {
            ObjectNode node = NODES.objectNode();
            node.put("type", "boolean");
            return node;
        }
        if (raw.isEnum()) {
            return enumSchema(raw);
        }
        if (raw.isArray()) {
            Class<?> component = raw.getComponentType();
            if (!isScalar(component)) {
                throw invalid("不支持对象数组");
            }
            ObjectNode node = NODES.objectNode();
            node.put("type", "array");
            node.set("items", scalarSchema(component));
            return node;
        }
        if (Map.class.isAssignableFrom(raw) || Set.class.isAssignableFrom(raw)
                || Optional.class.isAssignableFrom(raw) || raw == Object.class) {
            throw invalid("不支持的参数类型: " + raw.getName());
        }
        if (List.class.isAssignableFrom(raw)) {
            if (!(generic instanceof ParameterizedType parameterized)) {
                throw invalid("集合必须声明元素类型");
            }
            Type argument = parameterized.getActualTypeArguments()[0];
            if (!(argument instanceof Class<?> element) || !isScalar(element)) {
                throw invalid("只支持标量集合");
            }
            ObjectNode node = NODES.objectNode();
            node.put("type", "array");
            node.set("items", scalarSchema(element));
            return node;
        }
        if (Temporal.class.isAssignableFrom(raw) || Date.class.isAssignableFrom(raw)
                || raw.getName().startsWith("java.sql.")) {
            throw invalid("不支持日期时间参数");
        }
        if (raw.isPrimitive() || raw.getName().startsWith("java.")) {
            throw invalid("不支持的参数类型: " + raw.getName());
        }
        return objectSchema(raw, stack);
    }

    private static boolean isScalar(Class<?> type) {
        return type == String.class || type == char.class || type == Character.class
                || type == int.class || type == Integer.class
                || type == long.class || type == Long.class
                || type == short.class || type == Short.class
                || type == byte.class || type == Byte.class
                || type == float.class || type == Float.class
                || type == double.class || type == Double.class
                || type == BigDecimal.class
                || type == boolean.class || type == Boolean.class
                || type.isEnum();
    }

    private static ObjectNode scalarSchema(Class<?> type) {
        if (type == String.class || type == char.class || type == Character.class) {
            return stringSchema();
        }
        if (type.isEnum()) {
            return enumSchema(type);
        }
        if (type == boolean.class || type == Boolean.class) {
            ObjectNode node = NODES.objectNode();
            node.put("type", "boolean");
            return node;
        }
        if (type == float.class || type == Float.class || type == double.class || type == Double.class
                || type == BigDecimal.class) {
            ObjectNode node = NODES.objectNode();
            node.put("type", "number");
            return node;
        }
        ObjectNode node = NODES.objectNode();
        node.put("type", "integer");
        return node;
    }

    private static ObjectNode stringSchema() {
        ObjectNode node = NODES.objectNode();
        node.put("type", "string");
        return node;
    }

    private static ObjectNode enumSchema(Class<?> type) {
        ObjectNode node = NODES.objectNode();
        node.put("type", "string");
        ArrayNode values = node.putArray("enum");
        for (Object constant : type.getEnumConstants()) {
            values.add(((Enum<?>) constant).name());
        }
        return node;
    }

    private static ConfigurationException invalid(String message) {
        return new ConfigurationException(LumiRoseErrorCode.CONFIG_INVALID, message);
    }
}
```

```java
import com.fasterxml.jackson.databind.DeserializationFeature;

import java.util.Collections;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

public final class ToolContext {
    private final Map<String, Tool> tools;
    private final ObjectMapper mapper;

    private ToolContext(Builder builder) {
        this.tools = Collections.unmodifiableMap(new LinkedHashMap<>(builder.tools));
        this.mapper = new ObjectMapper()
                .configure(DeserializationFeature.FAIL_ON_UNKNOWN_PROPERTIES, false);
    }

    public List<Tool> tools() {
        return List.copyOf(tools.values());
    }

    public String execute(String name, String arguments) {
        Tool tool = tools.get(name);
        if (tool == null) {
            throw new ToolException(LumiRoseErrorCode.TOOL_NOT_FOUND, name, "未注册的工具: " + name);
        }
        String json = arguments == null || arguments.isBlank() ? "{}" : arguments;
        ToolParameters parameters;
        try {
            parameters = mapper.readValue(json, tool.parametersClass());
        } catch (IOException e) {
            throw new ToolException(LumiRoseErrorCode.TOOL_ARGS_INVALID, name, "工具参数解析失败", e);
        }
        try {
            return tool.execute(parameters);
        } catch (LumiRoseException e) {
            throw e;
        } catch (Exception e) {
            throw new ToolException(LumiRoseErrorCode.TOOL_EXECUTION_FAILED, name, "工具执行失败", e);
        }
    }

    public static Builder builder() {
        return new Builder();
    }

    public static final class Builder {
        private final Map<String, Tool> tools = new LinkedHashMap<>();

        public Builder register(Tool tool) {
            if (tool == null) {
                throw new ConfigurationException(LumiRoseErrorCode.CONFIG_INVALID, "tool 不能为空");
            }
            if (tools.containsKey(tool.name())) {
                throw new ConfigurationException(LumiRoseErrorCode.CONFIG_INVALID,
                        "工具重名: " + tool.name());
            }
            tools.put(tool.name(), tool);
            return this;
        }

        public Builder registerAll(Collection<Tool> tools) {
            if (tools == null) {
                throw new ConfigurationException(LumiRoseErrorCode.CONFIG_INVALID, "tools 不能为空");
            }
            tools.forEach(this::register);
            return this;
        }

        public ToolContext build() {
            return new ToolContext(this);
        }
    }
```

```java
package io.github.xxxyjade.lumirose.tool.impl;

import io.github.xxxyjade.lumirose.common.exception.ConfigurationException;
import io.github.xxxyjade.lumirose.common.exception.LumiRoseErrorCode;
import io.github.xxxyjade.lumirose.common.exception.ToolException;

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.InvalidPathException;
import java.nio.file.Path;

final class Workspace {
    private final Path root;

    Workspace(Path workspace) {
        if (workspace == null) {
            throw new ConfigurationException(LumiRoseErrorCode.CONFIG_INVALID, "workspace 不能为空");
        }
        try {
            Path absolute = workspace.toAbsolutePath().normalize();
            if (!Files.isDirectory(absolute)) {
                throw new ConfigurationException(LumiRoseErrorCode.CONFIG_INVALID,
                        "workspace 必须是已存在的目录");
            }
            this.root = absolute.toRealPath();
        } catch (IOException e) {
            throw new ConfigurationException(LumiRoseErrorCode.CONFIG_INVALID,
                    "workspace 无法解析", e);
        }
    }

    Path resolve(String rawPath, String toolName) {
        if (rawPath == null || rawPath.isBlank()) {
            throw new ToolException(LumiRoseErrorCode.TOOL_PATH_INVALID, toolName, "路径不能为空");
        }
        Path relative;
        try {
            relative = Path.of(rawPath);
        } catch (InvalidPathException e) {
            throw new ToolException(LumiRoseErrorCode.TOOL_PATH_INVALID, toolName, "路径非法", e);
        }
        if (relative.isAbsolute()) {
            throw new ToolException(LumiRoseErrorCode.TOOL_PATH_INVALID, toolName, "不允许绝对路径");
        }
        Path resolved = root.resolve(relative).normalize();
        if (!resolved.startsWith(root)) {
            throw new ToolException(LumiRoseErrorCode.TOOL_PATH_INVALID, toolName, "路径越界");
        }
        try {
            if (Files.exists(resolved)) {
                Path real = resolved.toRealPath();
                if (!real.startsWith(root)) {
                    throw new ToolException(LumiRoseErrorCode.TOOL_PATH_INVALID, toolName, "路径越界");
                }
                return real;
            }
            Path parent = resolved.getParent();
            if (parent != null && Files.exists(parent)) {
                Path realParent = parent.toRealPath();
                if (!realParent.startsWith(root)) {
                    throw new ToolException(LumiRoseErrorCode.TOOL_PATH_INVALID, toolName, "路径越界");
                }
            }
            return resolved;
        } catch (IOException e) {
            throw new ToolException(LumiRoseErrorCode.TOOL_PATH_INVALID, toolName, "路径非法", e);
        }
    }
}
```

#### `tool/impl/AtomicWrite.java`

```java
package io.github.xxxyjade.lumirose.tool.impl;

import io.github.xxxyjade.lumirose.common.exception.LumiRoseErrorCode;
import io.github.xxxyjade.lumirose.common.exception.ToolException;

import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.AtomicMoveNotSupportedException;
import java.nio.file.FileAlreadyExistsException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardCopyOption;

final class AtomicWrite {
    private AtomicWrite() {
    }

    static void write(Path target, String content, boolean overwrite, String toolName) {
        Path parent = target.getParent();
        Path temp = null;
        try {
            temp = Files.createTempFile(parent, ".lumirose-", ".tmp");
            Files.write(temp, content.getBytes(StandardCharsets.UTF_8));
            if (overwrite) {
                try {
                    Files.move(temp, target, StandardCopyOption.ATOMIC_MOVE,
                            StandardCopyOption.REPLACE_EXISTING);
                } catch (AtomicMoveNotSupportedException | UnsupportedOperationException e) {
                    Files.move(temp, target, StandardCopyOption.REPLACE_EXISTING);
                }
            } else {
                try {
                    Files.move(temp, target, StandardCopyOption.ATOMIC_MOVE);
                } catch (AtomicMoveNotSupportedException | UnsupportedOperationException e) {
                    Files.move(temp, target);
                }
            }
            temp = null;
        } catch (FileAlreadyExistsException e) {
            throw new ToolException(LumiRoseErrorCode.TOOL_FILE_EXISTS, toolName, "文件已存在", e);
        } catch (IOException | SecurityException e) {
            throw new ToolException(LumiRoseErrorCode.TOOL_EXECUTION_FAILED, toolName, "文件写入失败", e);
        } finally {
            if (temp != null) {
                try {
                    Files.deleteIfExists(temp);
                } catch (IOException ignored) {
                    // 临时文件清理失败不覆盖原始错误
                }
            }
        }
    }
}
```

```java
final class SseAccumulator {
    private static final ObjectMapper MAPPER = new ObjectMapper();

    private SseAccumulator() {
    }

    static ChatCompletionResponse consume(BufferedSource source, Consumer<String> onContent)
            throws IOException {
        State state = new State(onContent == null ? ignored -> { } : onContent);
        StringBuilder data = null;
        while (true) {
            String line = source.readUtf8Line();
            if (line == null) {
                break;
            }
            if (line.endsWith("\r")) {
                line = line.substring(0, line.length() - 1);
            }
            if (line.isEmpty()) {
                if (data != null) {
                    process(state, data.toString());
                    data = null;
                    if (state.done) {
                        break;
                    }
                }
                continue;
            }
            if (line.startsWith(":")) {
                continue;
            }
            int colon = line.indexOf(':');
            String field = colon < 0 ? line : line.substring(0, colon);
            String value = colon < 0 ? "" : line.substring(colon + 1);
            if (value.startsWith(" ")) {
                value = value.substring(1);
            }
            if ("data".equals(field)) {
                if (data == null) {
                    data = new StringBuilder();
                } else {
                    data.append('\n');
                }
                data.append(value);
            }
        }
        if (!state.done && data != null) {
            process(state, data.toString());
        }
        if (!state.done || state.finishReason == null || state.finishReason.isBlank()) {
            throw invalid("流式响应缺少结束标记或 finish_reason");
        }
        List<ChatCompletionToolCall> calls = new ArrayList<>();
        for (ToolCallBuilder builder : state.toolCalls.values()) {
            calls.add(builder.build());
        }
        String content = state.content.isEmpty() ? null : state.content.toString();
        String reasoning = state.reasoning.isEmpty() ? null : state.reasoning.toString();
        ChatCompletionMessage message = new ChatCompletionMessage(
                MessageRole.ASSISTANT, content, reasoning, null, calls);
        ChatCompletionChoice choice = new ChatCompletionChoice(0, message, state.finishReason);
        return new ChatCompletionResponse(List.of(choice), state.usage);
    }

    private static void process(State state, String data) {
        if ("[DONE]".equals(data)) {
            state.done = true;
            return;
        }
        JsonNode root;
        try {
            root = MAPPER.readTree(data);
        } catch (JsonProcessingException e) {
            throw invalid("流式响应 JSON 非法", e);
        }
        JsonNode choices = root.path("choices");
        if (!choices.isArray() || choices.isEmpty()) {
            throw invalid("流式响应缺少 choices");
        }
        JsonNode first = choices.get(0);
        JsonNode delta = first.path("delta");
        if (delta.isObject()) {
            JsonNode content = delta.get("content");
            if (content != null && !content.isNull()) {
                String text = content.asText();
                state.content.append(text);
                if (!text.isEmpty()) {
                    state.onContent.accept(text);
                }
            }
            JsonNode reasoning = delta.get("reasoning_content");
            if (reasoning != null && !reasoning.isNull()) {
                state.reasoning.append(reasoning.asText());
            }
            JsonNode toolCalls = delta.get("tool_calls");
            if (toolCalls != null && toolCalls.isArray()) {
                for (JsonNode toolCall : toolCalls) {
                    mergeToolCall(state, toolCall);
                }
            }
        }
        JsonNode finishReason = first.get("finish_reason");
        if (finishReason != null && !finishReason.isNull()) {
            state.finishReason = finishReason.asText();
        }
        JsonNode usage = root.get("usage");
        if (usage != null && !usage.isNull()) {
            state.usage = parseUsage(usage);
        }
    }

    private static void mergeToolCall(State state, JsonNode node) {
        int index = node.path("index").asInt();
        ToolCallBuilder builder = state.toolCalls.computeIfAbsent(index, ignored -> new ToolCallBuilder());
        String id = text(node, "id");
        if (id != null) {
            if (builder.id != null && !builder.id.equals(id)) {
                throw invalid("tool call id 冲突");
            }
            builder.id = id;
        }
        String type = text(node, "type");
        if (type != null) {
            builder.type = type;
        }
        JsonNode function = node.get("function");
        if (function != null && function.isObject()) {
            String name = text(function, "name");
            if (name != null) {
                if (builder.name != null && !builder.name.equals(name)) {
                    throw invalid("tool call name 冲突");
                }
                builder.name = name;
            }
            String arguments = text(function, "arguments");
            if (arguments != null) {
                builder.arguments.append(arguments);
            }
        }
    }

    private static ChatCompletionUsage parseUsage(JsonNode usage) {
        return new ChatCompletionUsage(
                integer(usage, "prompt_tokens"),
                integer(usage, "completion_tokens"),
                integer(usage, "total_tokens"));
    }

    private static Integer integer(JsonNode node, String field) {
        JsonNode value = node.get(field);
        return value == null || value.isNull() ? null : value.asInt();
    }

    private static String text(JsonNode node, String field) {
        JsonNode value = node.get(field);
        return value == null || value.isNull() ? null : value.asText();
    }

    private static ClientException invalid(String message) {
        return new ClientException(LumiRoseErrorCode.CLIENT_RESPONSE_INVALID, message);
    }

    private static ClientException invalid(String message, Throwable cause) {
        return new ClientException(LumiRoseErrorCode.CLIENT_RESPONSE_INVALID, message, cause);
    }

    private static final class State {
        private final Consumer<String> onContent;
        private final StringBuilder content = new StringBuilder();
        private final StringBuilder reasoning = new StringBuilder();
        private final Map<Integer, ToolCallBuilder> toolCalls = new TreeMap<>();
        private ChatCompletionUsage usage;
        private String finishReason;
        private boolean done;

        private State(Consumer<String> onContent) {
            this.onContent = onContent;
        }
    }

    private static final class ToolCallBuilder {
        private String id;
        private String type;
        private String name;
        private final StringBuilder arguments = new StringBuilder();

        private ChatCompletionToolCall build() {
            if (id == null || id.isBlank() || name == null || name.isBlank()) {
                throw invalid("tool call 结构不完整");
            }
            return new ChatCompletionToolCall(id, type, new ChatCompletionToolCall.Function(
                    name, arguments.toString()));
        }
    }
```

```java
                .readTimeout(Duration.ofSeconds(120))
                .retryOnConnectionFailure(false)
                .build();

    public ChatCompletionResponse chatCompletion(ChatCompletionRequest request) {
        return chatCompletion(request, ignored -> { });
    }

    public ChatCompletionResponse chatCompletion(ChatCompletionRequest request,
                                                 Consumer<String> onContent) {
        ObjectNode body = mapper.createObjectNode();
        body.put("model", model);
        body.set("messages", mapper.valueToTree(request.messages()));
        if (!request.tools().isEmpty()) {
            body.set("tools", mapper.valueToTree(request.tools()));
        }
        body.put("stream", true);
        Integer limit = request.maxTokens() != null ? request.maxTokens() : maxTokens;
        if (limit != null) {
            body.put("max_tokens", limit);
        }

        Request httpRequest = new Request.Builder()
                .url(baseUrl + "/chat/completions")
                .header("Authorization", "Bearer " + apiKey)
                .header("Content-Type", "application/json; charset=utf-8")
                .header("Accept", "text/event-stream")
                .post(RequestBody.create(body.toString(), JSON))
                .build();

        try (Response response = httpClient.newCall(httpRequest).execute()) {
            if (!response.isSuccessful()) {
                throw httpError(response);
            }
            if (response.body() == null) {
                throw new ClientException(LumiRoseErrorCode.CLIENT_RESPONSE_INVALID, "流式响应为空");
            }
            return SseAccumulator.consume(response.body().source(), onContent);
        } catch (IOException e) {
            throw new ClientException(LumiRoseErrorCode.CLIENT_IO_ERROR, "网络请求失败", e);
        }
    }

    private ClientException httpError(Response response) {
        int status = response.code();
        String code = null;
        String type = null;
        try {
            String body = response.body() == null ? "" : response.body().string();
            JsonNode error = mapper.readTree(body).path("error");
            code = textOrNull(error, "code");
            type = textOrNull(error, "type");

            // 错误体不可解析时只保留状态码

            message.append(" (");
            if (code != null) {
                message.append("code=").append(code);
            }
            if (code != null && type != null) {
                message.append(", ");
            }
            if (type != null) {
                message.append("type=").append(type);
            }
            message.append(")");
        }
        return new ClientException(LumiRoseErrorCode.CLIENT_HTTP_ERROR, status, message.toString());
    }

    private static String textOrNull(JsonNode node, String field) {
        JsonNode value = node.get(field);

    }

        }
        return value;
    }

            this.model = model;

            return this;
        }
```

```java
            ChatCompletionMessage message = choice.message();
            if (message == null) {
                throw new AgentException(LumiRoseErrorCode.AGENT_RESPONSE_INVALID, "模型响应语义非法");
            }
            String text = message.content();
            if (text != null) {
                allContent.append(text);
            }
            lastUsage = response.usage();
            FinishReason finishReason = FinishReason.fromWire(choice.finishReason());
            if (finishReason == FinishReason.LENGTH) {
                throw new AgentException(LumiRoseErrorCode.AGENT_OUTPUT_TRUNCATED, "模型输出被截断");
            }
            if (finishReason == null) {
                throw new AgentException(LumiRoseErrorCode.AGENT_RESPONSE_INVALID, "模型响应语义非法");
            }
            boolean hasToolCalls = message.toolCalls() != null && !message.toolCalls().isEmpty();
            if (hasToolCalls) {
                Message assistant = Message.assistant(text, message.reasoningContent(),
                        toEntityToolCalls(message.toolCalls()));
                pending.add(assistant);
                for (ChatCompletionToolCall call : message.toolCalls()) {
                    checkCancelled(result);
                    String name = validateToolCall(call);
                    String toolResult = toolContext.execute(name, call.function().arguments());
                    pending.add(Message.tool(call.id(), toolResult == null ? "" : toolResult));
                    checkCancelled(result);
                }
                continue;
            }
            if (finishReason != FinishReason.STOP) {
                throw new AgentException(LumiRoseErrorCode.AGENT_RESPONSE_INVALID, "模型响应语义非法");
            }
            if (text == null || text.isBlank()) {
                throw new AgentException(LumiRoseErrorCode.AGENT_RESPONSE_INVALID, "模型响应语义非法");
            }
            pending.add(Message.assistant(text, message.reasoningContent(), List.of()));
            finalText = text;
            break;
        }

        if (finalText == null) {
            throw new AgentException(LumiRoseErrorCode.AGENT_TURN_LIMIT, "轮次用尽");
        }
        checkCancelled(result);
        Integer contextTokens = contextTokens(lastUsage);
        if (contextTokens == null) {
            if (compressed) {
                throw new AgentException(LumiRoseErrorCode.AGENT_COMPRESSION_FAILED,
                        "上下文压缩失败");
            }
            contextTokens = conversation.contextTokens();
            log.warn("usage 缺失，保留旧 contextTokens: conversationId={} tokens={}",
                    conversationId, contextTokens);
        }
        if (compressed) {
            repository.compact(conversationId, summary, pending, contextTokens);
        } else {
            repository.append(conversationId, pending, contextTokens);
        }
        int promptTokens = lastUsage == null ? 0 : nullSafe(lastUsage.promptTokens());
        int completionTokens = lastUsage == null ? 0 : nullSafe(lastUsage.completionTokens());
        result.complete(allContent.toString(), promptTokens, completionTokens);
    }

    private ChatCompletionResponse requestWithRetry(ChatCompletionRequest request, AgentResult result) {
        int attempt = 0;
        boolean[] delivered = {false};
        while (true) {
            checkCancelled(result);
            try {
                return client.chatCompletion(request, delta -> {
                    delivered[0] = true;
                    if (result.streaming()) {
                        result.emit(delta);
                    }
                });
            } catch (ClientException e) {
                if (!e.retriable() || delivered[0] || attempt >= maxRetries) {
                    throw e;
                }
                attempt++;
                long delay = retryDelay(attempt);
                log.debug("retry: attempt={} delayMs={} code={}",
                        attempt, delay, e.getErrorCode().code());
                backoff(delay, result);
            }
        }
    }

    private void backoff(long delayMillis, AgentResult result) {
        long deadline = System.nanoTime() + delayMillis * 1_000_000L;
        while (true) {
            checkCancelled(result);
            long remaining = deadline - System.nanoTime();
            if (remaining <= 0) {
                return;
            }
            long slice = Math.min(50L, Math.max(1L, remaining / 1_000_000L));
            try {
                Thread.sleep(slice);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                throw new AgentException(LumiRoseErrorCode.AGENT_CANCELLED, "退避等待被中断");
            }
        }
    }

    private long retryDelay(int attempt) {
        long delay = retryBaseDelayMillis;
        for (int i = 1; i < attempt; i++) {
            delay = Math.min(retryMaxDelayMillis, delay * 2);
        }
        return Math.min(delay, retryMaxDelayMillis);
    }

    private ChatCompletionRequest requestFor(List<Message> base, List<Message> pending,
                                             String system) {
        List<ChatCompletionMessage> messages = new ArrayList<>();
        if (system != null) {
            messages.add(ChatCompletionMessage.system(system));
        }
        for (Message message : base) {
            messages.add(toDto(message));
        }
        for (Message message : pending) {
            messages.add(toDto(message));
        }
        List<ChatCompletionTool> tools = new ArrayList<>();
        for (Tool tool : toolContext.tools()) {
            tools.add(new ChatCompletionTool("function", new ChatCompletionTool.Function(
                    tool.name(), tool.description(),
                    ToolSchemaFactory.generate(tool.parametersClass()))));
        }
        return new ChatCompletionRequest(messages, tools, null);
    }

    private ChatCompletionMessage toDto(Message message) {
        return switch (message.role()) {
            case SYSTEM -> ChatCompletionMessage.system(message.content());
            case USER -> ChatCompletionMessage.user(message.content());
            case ASSISTANT -> ChatCompletionMessage.assistant(message.content(),
                    message.reasoningContent(), toDtoToolCalls(message.toolCalls()));
            case TOOL -> ChatCompletionMessage.tool(message.toolCallId(), message.content());
        };
    }

    private List<ChatCompletionToolCall> toDtoToolCalls(List<ToolCall> toolCalls) {
        List<ChatCompletionToolCall> result = new ArrayList<>();
        for (ToolCall toolCall : toolCalls) {
            result.add(new ChatCompletionToolCall(toolCall.id(), toolCall.type(),
                    new ChatCompletionToolCall.Function(toolCall.name(), toolCall.arguments())));
        }
        return result;
    }

    private List<ToolCall> toEntityToolCalls(List<ChatCompletionToolCall> toolCalls) {
        List<ToolCall> result = new ArrayList<>();
        for (ChatCompletionToolCall toolCall : toolCalls) {
            validateToolCall(toolCall);
            result.add(new ToolCall(toolCall.id(), toolCall.type(),
                    toolCall.function().name(), toolCall.function().arguments()));
        }
        return result;
    }

    private static String validateToolCall(ChatCompletionToolCall toolCall) {
        if (toolCall == null || toolCall.id() == null || toolCall.id().isBlank()
                || toolCall.function() == null || toolCall.function().name() == null
                || toolCall.function().name().isBlank()) {
            throw new AgentException(LumiRoseErrorCode.AGENT_RESPONSE_INVALID, "工具调用结构非法");
        }
        return toolCall.function().name();
    }

    private boolean shouldCompress(Conversation conversation) {
        return contextWindowTokens != null
                && !conversation.messages().isEmpty()
                && conversation.contextTokens() > contextWindowTokens * contextCompressionThreshold;
    }

    private Message compress(List<Message> history) {
        try {
            List<ChatCompletionMessage> messages = new ArrayList<>();
            messages.add(ChatCompletionMessage.system(COMPRESSION_PROMPT));
            for (Message message : history) {
                messages.add(toDto(message));
            }
            ChatCompletionRequest request = new ChatCompletionRequest(
                    messages, List.of(), summaryMaxTokens());
            ChatCompletionResponse response = client.chatCompletion(request);
            if (response.choices().isEmpty()) {
                throw new AgentException(LumiRoseErrorCode.AGENT_COMPRESSION_FAILED, "上下文压缩失败");
            }
            ChatCompletionChoice choice = response.choices().get(0);
            FinishReason finish = FinishReason.fromWire(choice.finishReason());
            if (finish != FinishReason.STOP) {
                throw new AgentException(LumiRoseErrorCode.AGENT_COMPRESSION_FAILED, "上下文压缩失败");
            }
            ChatCompletionMessage message = choice.message();
            if (message == null || message.content() == null || message.content().isBlank()) {
                throw new AgentException(LumiRoseErrorCode.AGENT_COMPRESSION_FAILED, "上下文压缩失败");
            }
            return Message.assistant(COMPRESSION_HEADER + "\n" + message.content(), null, List.of());
        } catch (LumiRoseException e) {
            if (e.getErrorCode() == LumiRoseErrorCode.AGENT_CANCELLED) {
                throw e;
            }
            if (e.getErrorCode() == LumiRoseErrorCode.AGENT_COMPRESSION_FAILED) {
                throw e;
            }
            throw new AgentException(LumiRoseErrorCode.AGENT_COMPRESSION_FAILED, "上下文压缩失败", e);
        }
    }

    private int summaryMaxTokens() {
        double value = contextWindowTokens * (1.0 - contextCompressionThreshold) * 0.7;
        return Math.min(SUMMARY_MAX_TOKENS_CAP, Math.max(1, (int) Math.floor(value)));
    }

    private static Integer contextTokens(ChatCompletionUsage usage) {
        if (usage == null) {
            return null;
        }
        if (usage.totalTokens() != null) {
            return usage.totalTokens();
        }
        if (usage.promptTokens() != null || usage.completionTokens() != null) {
            return nullSafe(usage.promptTokens()) + nullSafe(usage.completionTokens());
        }
        return null;
    }

    private static int nullSafe(Integer value) {
        return value == null ? 0 : value;
    }

    private static void checkCancelled(AgentResult result) {
        if (result.isCancelled()) {
            throw new AgentException(LumiRoseErrorCode.AGENT_CANCELLED, "运行已取消");
        }
    }

    private static final class AgentResult implements LumiRoseResult {
        private static final String DONE = new String("<DONE>");

        private final boolean streaming;
        private final BlockingQueue<String> deltas = new LinkedBlockingQueue<>();
        private final AtomicBoolean started = new AtomicBoolean();
        private final AtomicBoolean cancelled = new AtomicBoolean();
        private final AtomicBoolean deltasRequested = new AtomicBoolean();
        private volatile Runnable starter;
        private volatile String content;
        private volatile int promptTokens;
        private volatile int completionTokens;
        private volatile boolean completed;
        private volatile boolean contentReady;
        private volatile LumiRoseException failure;

        private AgentResult(boolean streaming) {
            this.streaming = streaming;
        }

        private void setStarter(Runnable starter) {
            this.starter = starter;
        }

        private boolean streaming() {
            return streaming;
        }

        @Override
        public String content() {
            requireCompleted();
            return content;
        }

        @Override
        public int promptTokens() {
            requireCompleted();
            return promptTokens;
        }

        @Override
        public int completionTokens() {
            requireCompleted();
            return completionTokens;
        }

        @Override
        public Iterable<String> deltas() {
            if (!deltasRequested.compareAndSet(false, true)) {
                throw new IllegalStateException("deltas() 只能消费一次");
            }
            return () -> new Iterator<>() {
                private String next;
                private boolean finished;

                @Override
                public boolean hasNext() {
                    if (finished) {
                        return false;
                    }
                    if (next != null) {
                        return true;
                    }
                    start();
                    try {
                        String value = deltas.take();
                        if (value == DONE) {
                            finished = true;
                            if (failure != null) {
                                throw failure;
                            }
                            contentReady = true;
                            return false;
                        }
                        next = value;
                        return true;
                    } catch (InterruptedException e) {
                        Thread.currentThread().interrupt();
                        throw new AgentException(LumiRoseErrorCode.AGENT_CANCELLED, "等待增量被中断");
                    }
                }

                @Override
                public String next() {
                    if (!hasNext()) {
                        throw new NoSuchElementException();
                    }
                    String value = next;
                    next = null;
                    return value;
                }
            };
        }

        @Override
        public void cancel() {
            if (completed) {
                return;
            }
            cancelled.set(true);
            if (failure == null) {
                failure = new AgentException(LumiRoseErrorCode.AGENT_CANCELLED, "运行已取消");
            }
            deltas.offer(DONE);
        }

        private boolean isCancelled() {
            return cancelled.get();
        }

        private void emit(String delta) {
            if (streaming && !cancelled.get() && !completed) {
                deltas.offer(delta);
            }
        }

        private void complete(String content, int promptTokens, int completionTokens) {
            if (completed || failure != null || cancelled.get()) {
                return;
            }
            this.content = content;
            this.promptTokens = promptTokens;
            this.completionTokens = completionTokens;
            this.completed = true;
            if (!streaming) {
                this.contentReady = true;
            }
            deltas.offer(DONE);
        }

        private void fail(LumiRoseException error) {
            if (completed) {
                return;
            }
            if (failure == null) {
                failure = error;
            }
            deltas.offer(DONE);
        }

        private void start() {
            if (!started.compareAndSet(false, true)) {
                return;
            }
            if (cancelled.get()) {
                return;
            }
            Runnable task = starter;
            if (task != null) {
                Thread.ofVirtual().name("lumirose-agent").start(task);
            }
        }

        private void requireCompleted() {
            if (!contentReady) {
                throw new IllegalStateException("结果尚未完成");
            }
        }
    }

                throw configuration("contextCompressionThreshold 必须在 (0,1) 内");
            }
            return new LumiRoseAgent(this);
        }

        }
    }
```
